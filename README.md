1.1.	Добавлены текстовые значения при замене строк.

1.2.	Добавлено преобразование ФИО из родительного падежа в именительный.

1.3.	Добавлено логирование и tkinter для отображения ошибок.

1.4.	Добавлено улучшенное логирование и блоки try-except.

1.5.	Добавлено удаление пробелов в начале и конце ИР, ФР, ОР и пропуск, если этих кодов нет.

1.6.	Поиск значений в файлах RT.

1.12.	Временный блок по замене -ПР на -ПИ.

1.13.	Внесение почтового индекса в графу ИНД из postal_codes.xlsx.

1.14.	Ограничение записи преобразованных значений ФИО в ячейки именительного падежа только для ЭКЦ.

1.15.	Оптимизация поиска и присвоения значений RT: раннее прерывание при нахождении нужного объекта, вместо нового поиска для заполнения каждой ячейки реализован однократный поиск с записью всех значений.

1.15.1.	Возвращён полный поиск вместо раннего прерывания, добавлен механизм выбора при обнаружении одинаковых названий объектов.

1.15.2.	Поиск в RT производится не по 4 и 5 столбцам по порядку, а с учётом заголовка Quantity и Degradation Index Mean.
