# Программа для чтения данных из файла Excel (Карты), замены ФИО в родительном падеже на именительный, поиска значений в папке РТ

1.1.	Добавлены текстовые значения при замене строк.

1.2.	Добавлено преобразование ФИО из родительного падежа в именительный.

1.3.	Добавлено логирование и tkinter для отображения ошибок.

1.4.	Добавлено улучшенное логирование и блоки try-except.

1.5.	Добавлено удаление пробелов в начале и конце ИР, ФР, ОР и пропуск, если этих кодов нет.

1.6.	Поиск значений в файлах RT.

1.7.	Если ИД<1, в ячейку записывается 0; в РТ точки заменяются на запятые; при отсутствии ОБРТ во всех файлах РТ выдаётся ошибка.

1.8.	Очистка в Карте строк с РТ, для которых значение ОБРТ пусто; отсутствие значения в графе ОБРТ завершается ошибкой только в случае работы с костями.

1.9.	Проверка на условие, если ДМ в Карте "ниже порога детекции", но в файле RT есть значение, и поэтому есть значение в ячейке ИД.
